# 🏡 House Price Prediction using Machine Learning

## 📌 Project Overview
This project focuses on predicting house prices using Machine Learning techniques. A Linear Regression model is trained on a housing dataset to understand relationships between housing features and prices and generate price predictions.

## 🎯 Objectives
- Understand and analyze housing data.
- Perform Exploratory Data Analysis (EDA).
- Visualize important data patterns.
- Train a Linear Regression model.
- Evaluate model performance.
- Predict house prices using the trained model.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## ⚙️ Project Workflow
1. Dataset loading
2. Data exploration and preprocessing
3. Missing value checking
4. Exploratory Data Analysis (EDA)
5. Data visualization
6. Training and testing data splitting
7. Linear Regression model training
8. Model evaluation using MAE, RMSE, and R² Score
9. Sample house price prediction

## 🤖 Machine Learning Algorithm
**Linear Regression**

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by identifying relationships between input features and the target variable.

## 📊 Model Evaluation
The model was evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📁 Project Files
- `House_Price_Prediction.ipynb` – Google Colab notebook containing the complete project.
- `house_price_model.pkl` – Saved trained Machine Learning model.
